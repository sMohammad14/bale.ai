🪶 توضیح: شما از طریق API ها نمیتونید به تمام کاربران گروهتون دسترسی داشته باشید
پس باید مانند یک کاربر، طوری رفتار کنیم که انگار یکی از اعضای گروه هستید و لیست رو باز کردید و تک تک کاربران رو انتخاب کردید


💡نحوه استفاده:
از طریق وب، وارد بله بشید، گروه مدنظر رو انتخاب کنید و وارد گروه بشید. بالا، روی اسم گروه کلیک کنید تا پنچره pop-up مربوط به گروه که شامل توضیحات و اعضا و ... هست نشون داده بشه. F12 رو بزنید، تب console رو وارد بشید و کد رو paste کنید. (ممکنه قبلش نیاز باشه تایپ کنید allow pasting و enter بزنید. اگر لازم بود خودش میگه). صبر کنید تا کار کد تمام بشه. در انتها یک آرایه از UID کاربران گروه دارید! که میتونید بزارید انتها لینک زیر و به صفحه کاربر مراجعه کنید!

https://web.bale.ai/chat?uid=xxxxxxxxxxxxx

🔦نکات:
این کد اسکرول خودکار میکنه و اگر هزاران کاربر داخل گروه باشن هم کار خواهد کرد. اسکرول هر 0.2 ثانیه یک بار رخ میده تا fetch کردن دیتا توس سرور محدود نشه. ممکنه با اپدیت های بله، کلاس مربوط به پنچره توضیحات گروه اسمش عوض بشه، اگر شد، توی خطا، پیام مناسب نشون داده میشه تا کد رو تغییر بدید و به روز کنید!
