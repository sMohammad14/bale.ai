### ارسال پیام به مخاطبین
نسخه مقاوم نسبت به مسدودسازی سمت سرور


🪶 توی این کد، به تمام مخاطبین پیام ارسال خواهد شد.

اگر توی پیام x بزارید، جای x اسم مخاطب درج میشه

15 قالب پیام در نظر گرفته شده تا به هر مخاطب، پیام یکسان نره و از طرف سرور مسدود بشید

پیام paste نمیشه، تایپ میشه که میتونید تاخیر ورودی کاراکتر ها رو هم با تاخیر تصادفی قرار بدید

اینکه بعد از چه تعداد پیام مکث تصادفی داشته باشه، هم خوده مکث و هم بعد از چه تعداد هم میتونه عدد تصادفی باشه که شما بازه رو براش مشخص میکنید

توصیه میشه 15 پیام همه شون شامل لینک نباشن، طوری باشن که مخاطبتون خودش ترغیب بشه و پیام بده و پرس و جو کنه

اگر طول آرایه از 15 کمتر یا بیشتر بشه کد خودش پیدا میکنه، مثلا شما 5 تا پیام نمونه بزارید هم نیازی به تغییر خوده کد نیست

هر تعداد پیام که رفت، در یک بازه تصادفی همه چیز متوقف خواهد شد

قابلیت مهم دیگه اینه که حتی اگر صفحه رفرش بشه یا هر چیزی، میتونید ببینید که کدام UID ها پیام ارسال شده، تا در اجرای بعدی کد به اون ها دوباره ارسال نشه، برای همین آرایه ای هم در نظر گرفته شده

همچنین برای ارسال پیام، دیگه UID و مخاطبین از طریق UI استفاده نخواهد شد، مستقیم میره سراغ دیتابیس محلی سمت کلاینت

این دو کامند برای UID های پیام ارسال شده هست

برای دیدن محتوا، به دو روش مستقیم و فراخوانی:


نمایش  لیست ارسال شده ها دستی:
``` localStorage.getItem('sentUIDs') ```


نمایش  لیست ارسال شده ها با تابع:
``` getSentUIDs() ```


پاکسازی لیست ارسال شده ها به صورت دستی:
``` localStorage.removeItem('sentUIDs') ```

پاکسازی لیست ارسال شده ها با تابع:
``` clearSentUIDs() ```
